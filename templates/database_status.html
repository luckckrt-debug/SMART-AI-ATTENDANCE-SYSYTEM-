MongoDB Configuration & Setup Guide

To connect the application to an active MongoDB database instead of the local SQLite storage engine, follow these steps:

If you have MongoDB installed on Windows, start the service: 
net start MongoDB
Or start mongod manually: 
mongod --dbpath "C:\data\db"

If using MongoDB Atlas, place your connection string in .env: 
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/?retryWrites=true&w=majority

When you reconnect to MongoDB, the system automatically runs _sync_sqlite_to_mongo() to copy all student profiles, classroom sessions, and attendance records into MongoDB.
